# Loading Screen (PC)

Canonical assets for the Render Studio desktop boot / loading animation.

| File | Role |
| --- | --- |
| `render-studio-logo.png` | Fixed top-left attribution logo on the loading screen (always shown; links to the GitHub repo) |
| `futuristic-gear-metal.png` | Gear progress mark used beside the product wordmark |
| `pc-loading-animation.svg` | Standalone reference of the PC printer + arm loading motion |

Served copies used by the app live under `frontend/assets/loading-screen/`.

Admins can replace the stage media and product logo/name from **Management dashboard → Server Settings**. The top-left Render Studio attribution logo is never replaced by those settings.
