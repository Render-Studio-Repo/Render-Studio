Where Render3D is headed

Render3D is evolving from an AI-assisted mesh viewer into a full parametric CAD workflow. Items below are grouped by phase — shipped capabilities first, then what comes next.

Shipped

  • Done
    3D viewport

    Orbit, pan, zoom, grid, fit-to-view, and Fusion-style scene lighting.

  • Done
    Mesh import & export

    STL, OBJ, GLB/GLTF, PLY, and OFF upload with timeline history.

  • Done
    AI CAD prompting

    Natural-language geometry generation and modification via GPT-5.5 Pro + Trimesh.

  • Done
    Geometric references

    Pick corners, faces, and edges; reference them in prompts with @corner-1 chips.

  • Done
    Transform gizmo

    Move, rotate, and scale parts with server-side persistence.

  • Done
    Keyboard shortcuts

    Hotkeys for navigation, picking, wireframe, and the transform gizmo — see table below.

Keyboard shortcuts

Shortcuts work in the Studio viewport when focus is not in a text field.

KeyAction
LMBOrbit camera
RMBPan camera
ScrollZoom
CPick corner mode
FPick face mode (click again to deselect; multiple faces supported)
EPick edge mode
WToggle wireframe
GAttach move gizmo
RSwitch gizmo to rotate (when gizmo is active)
SSwitch gizmo to scale (when gizmo is active)
EscExit pick / gizmo — return to orbit

Next up

  • Planned
    STEP / IGES import

    B-Rep support via Open CASCADE or CadQuery for professional CAD interchange.

  • Planned
    Parametric feature tree

    Sketch constraints, fillets, extrudes, and revolve operations with editable history.

  • Planned
    Multi-part assemblies

    Position multiple bodies, mate references, and export assembly GLB/STL.

  • Planned
    BOM export

    Bill of materials with part names, quantities, and material metadata.

Future

  • Exploring
    Collaborative editing

    Shared projects, live cursors, and comment threads on geometry.

  • Exploring
    Manufacturing outputs

    2D drawings, GD&T annotations, and CAM-ready exports.

  • Exploring
    Plugin SDK

    Custom importers, AI tools, and post-processing scripts.
