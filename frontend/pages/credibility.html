Credibility

Render Studio is a product studio, not a from-scratch CAD kernel. Generation, inspection, mesh rebuilds, and wiring graphics stand on public open-source projects. This page is the license and provenance map.

How to read this

Each card is a project we vendor, wrap, or call at runtime. License names are the upstream SPDX-style terms we ship against. Links go to the public repository or license text — not to a Render Studio fork unless that is the source of truth in this tree.

CAD engines

The CAD mode switcher (Jake, VibeCAD, MAC) is a harness over these runtimes. Viewport never loads raw STEP; kernels publish GLB for Three.js.

Jake · text-to-cad MIT Parametric CAD agent skills (@step, inspect, snapshot) from earthtojake/text-to-cad. Copyright Thompson Labs LLC. Installed locally under backend/skills/.
cadgen MIT STEP-first generation runtime used by Jake: build123d authoring, inspection, and CAD Viewer snapshots. Provenance: text-to-cad.
VibeCAD Upstream FreeCAD / build123d sidecar for Mode 2.0 VibeCAD. Adapted from 10-X-eng/vibecad. See that repository for the project license.
build123d Apache-2.0 Python CAD kernel used by Jake cadgen and the VibeCAD sidecar to emit STEP. gumyr/build123d.
FreeCAD LGPL-2.1+ Optional VibeCAD authoring path when FreeCADCmd is available. FreeCAD/FreeCAD.
Open CASCADE (OCCT) LGPL-2.1 Geometry kernel underneath build123d / FreeCAD STEP solids. dev.opencascade.org.

Mesh & viewport

img2threejs Apache-2.0 Procedural Three.js rebuild from a photo or text (Mesh mode). img2threejs/img2threejs · LICENSE.
Three.js MIT Studio viewport, CAD Viewer, and Mesh GLB playback. mrdoob/three.js.
three-mesh-bvh MIT Mesh picking / BVH acceleration in CAD Viewer. gkjohnson/three-mesh-bvh.
meshoptimizer MIT Bundled with cadgen-js viewer runtimes. zeux/meshoptimizer.

Wiring graphics

Fritzing parts CC BY-SA 3.0 Breadboard SVGs in the Wiring Simulator are a curated subset of fritzing/fritzing-parts. Credit: images created with Fritzing. CC BY-SA 3.0. Custom boards in wiring-parts/custom/ are original Render Studio drawings.

Jake skill pack (MIT)

These agent skills ship from text-to-cad and are MIT, Copyright (c) 2026 Thompson Labs LLC: CAD, CAD Viewer, URDF, SRDF, SDF, DXF, G-code, STEP parts, Bambu Labs, SendCutSend, DFM check. Local copies live under backend/skills/ with the upstream LICENSE file.

What this is not

McMaster-Carr catalog parts, Autodesk Fusion, Onshape, and model-provider APIs (OpenAI, Anthropic, and others) are licensed services or catalogs — not open-source kernels. They are not listed as OSS credits.
