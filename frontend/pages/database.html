Don’t have a project yet?

Supabase is safer for a shared instance: password hashes and Fernet-wrapped AI keys live behind RLS, not only in data/render3d.db on the box. Rotate keys in the dashboard without copying sqlite around.

  • Create a free project at supabase.com/dashboard/new.
  • Project Settings → API: copy the Project URL and service_role (server only). Publishable/anon is optional here.
  • Paste them below, apply the SQL, then Connect.

Connect your Supabase
