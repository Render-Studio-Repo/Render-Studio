Don’t have a project yet?

Supabase is safer for a shared instance: password hashes and Fernet-wrapped AI keys live behind RLS, not only in data/render3d.db on the box. Rotate keys in the dashboard without copying sqlite around.

  • Project Settings → API: copy the Project URL and service_role (server only). Publishable/anon is optional here.

Safe Render updates

      
Connected instances receive a review button when the public Render Studio repository publishes a stable update. Changes to render3d.app do not trigger this notice. Updates never replace projects/, data/, backups/, .env, credentials, or private instance modules. Any locally edited or added application source makes the update stop instead of overwriting it.
