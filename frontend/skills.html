Skills Library

Agent skills from text-to-cad — full Python tooling (step, inspect, snapshot, URDF, SDF, DXF, and more) synced to the server. Skills are available by default; Render Studio auto-selects the relevant ones for each prompt instead of injecting every skill every time. With CAD available, exported STEP files are validated via the skill's Python inspect tools after each build.

How it works

  • Skills available by default — CAD, Blueprint Vision, URDF, SDF, SRDF, DXF, step-parts, gcode, bambu-labs, cad-viewer, implicit-cad, sendcutsend, mold generation, and installed Agent Store skills.
  • Auto routing — prompts only inject the relevant skills, such as Blueprint Vision for images or Silicone Mold Generation for mold/casting requests.
  • Python tools — many skills ship scripts/ CLIs; Render Studio runs CAD inspect on STEP after builds when CAD is selected.
  • Sync updates — run scripts/sync-skills-from-text-to-cad.sh on the server to pull latest from GitHub.
