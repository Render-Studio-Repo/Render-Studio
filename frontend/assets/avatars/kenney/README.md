# Kenney avatar assets

Source: [Animated Characters Protagonists](https://kenney.nl/assets/animated-characters-protagonists), Kenney, CC0 (see License.txt).

Converted from the shared characterMedium FBX, the cyborgFemaleA/skaterFemaleA/skaterMaleA textures, and the idle animation. Each GLB has 1,604 triangles, a single shared material, and an idle animation; downloads are 670–683 KiB each. Loaded lazily and cached by selection. The renderer updates animation at 30 Hz and disables avatar shadows.

Studio's existing head pose and avatar source fields replicate the selection to other room users. These are local CC0 avatars, not authenticated Meta or Ready Player Me integrations.
