      In development

      Design phase

      Style and finish your wireframe — not available yet.

      After Build locks the bay layout, Design will let you pick visual styles without changing the floor-plan structure.

      Planned tools

      • Module library — corner walls, double windows, shelves, and other styled kits (the old Architect Library lives here).
      • Opening styles — swap generic door/window bays for specific insert designs.
      • Materials & colors — surface finishes on selected modules.
      • Customize — generative edits on a selected piece.

      What stays out of this phase

      • Drawing or deleting 3 ft bays (that stays in Build).
      • Floors, roofs, and multi-story stacking (Structure).

      Return to Build to keep wireframing. This tab is a roadmap preview until Design ships.

      In development

      Structure phase

      Levels, floors, roofs, and load-bearing layout — not available yet.

      Structure adds everything that turns a single-level wireframe into a full building shell.

      Planned tools

      • Levels — stack stories and switch the active floor.
      • Floor slabs — place floor modules on the bay grid.
      • Roof / ceiling — gable, flat, and corner roof kits.
      • Stairs & vertical circulation — connect levels once multi-story exists.
      • Service cores — utility shafts and structural cores.

      What stays out of this phase

      • Wall/door/window wireframing (Build).
      • Finishes, daylight, and comfort overlays (Comfort).

      This phase is planned, not interactive yet. Use Build for the current floor plan.

      In development

      Comfort phase

      Daylight, insulation, and living comfort — not available yet.

      Comfort is an inspector layer on top of the built structure — how the house feels to live in, not how the walls are drawn.

      Planned tools

      • Daylight — preview light from window bays.
      • Insulation / thermal — wall and roof comfort ratings.
      • Room labels — detected spaces with comfort targets.
      • Furniture & appliances — optional living layout overlays.

      What stays out of this phase

      • Placing structural bays or roofs.
      • Styled module kits (Design).

      Placeholder only — no comfort tools are live. Continue in Build.

      In development

      Review phase

      Check the plan and prepare export — not available yet.

      Review is the last stop before leaving Architect: confirm the bay plan, catch gaps, then hand off to export or robot kit.

      Planned tools

      • Plan checklist — open loops, missing doors, empty levels.
      • Dimensions summary — bay counts and footprint.
      • Export prep — printable / robot-kit connectors applied at export time only.
      • Snapshot — save a review image of the current level.

      What stays out of this phase

      • Editing walls or styles — jump back to Build or Design for that.

      Coming later. Your live tools are under the Build tab.
