      Direct modeling

      Use Select in the toolbar (V) to pick an object · Backspace or X to delete. Split bodies separates disconnected solids into individual files. Drag handles in the viewport; type values like 25mm or 1in.

      Color Select an object or pick faces, then apply.

      Drag the red/green/blue arrows in the viewport, or type X/Y/Z in the floating gizmo panel. Snap increments available.

      Drag the rotation rings around each axis, or type degrees in the gizmo panel. Toggle local/world space.

      Drag the scale handles on the gizmo, or type a uniform scale factor.

      Click a planar face — drag the blue arrow to join (pull) or cut (push). Options: symmetric, two-sided, taper, through-all, join/cut/intersect/new body.
