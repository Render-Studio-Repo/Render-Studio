      AI CAD Prompt

      Render Photoreal images

      Creates photoreal images from the current model, scene, lighting, materials, and camera direction.

      CAD Prompt Mode 2.0

      Builds CAD geometry by default: parametric parts, assemblies, dimensions, and named features.

      img2threejs Rebuild as procedural Three.js

      Uses the img2threejs pipeline: code-only primitives + PBR materials + hierarchy from a reference image or text — then loads the GLB in the viewport. Not CAD / STEP.

      2.0 Model electronics solids

      When your prompt mentions motors, servos, ESC, battery, or wiring, the agent can add visible labeled electronics and wire runs — not just empty pockets.

      • On: motor, ESC, battery, servo, and harness solids
      • Off: airframe/mechanical geometry only (faster builds)
      • Click the button to toggle before you generate
      During generate Codex CAD agent

      Checking this runs generation with the Codex CAD agent instead of the default in-app tool loop. Codex owns edit → step → inspect → snapshot → repair in one session, so geometry issues get caught before the model lands in the viewport.

      • Off: default Render3D tool agent (still builds CAD)
      • On: Codex self-checks with inspect + multi-view snapshots
      • Helps the agent fix orientation, fit, and failed builds mid-run
      • Requires an OpenAI API key
      Before generate Improve prompt with AI

      In Render, rewrites for a clearer photoreal image: scene, lighting, materials, and camera angle. In 2.0 / Fusion, rewrites for parametric CAD dimensions and named features.

      • On by default: polish the prompt for the active mode
      • Render saves an image; 2.0 builds CAD geometry
      • Tap to turn improve on or off
