Product roadmap

Where Render Studio is headed

Render Studio already ships a serious Studio for AI CAD, XR review, robotics workflows, and in-product guidance. The roadmap below focuses on the next layer: a clearer Workshop direction, stronger VR flows, and more deliberate robot operations.

Shipped

  • Done
    WebXR review and AI-in-headset controls Shipped Jul 2026

    Quest-oriented XR sessions, world-space panels, AI VR controls, screenshots, and recording already ship inside the product.

    Use it: enter XR from Studio, open the floating menu, and review or capture the same project in-headset.

  • Done
    Robotics runtime and motion-ready assets Shipped Jul 2026

    Render Studio already supports rigging, URDF/SRDF workflows, robot playback, and optional MoveIt2-backed planning hooks.

    Use it: switch to Robotics or Rigging, load a robot asset, and review movement inside the main viewport.

  • Done
    Project creation, approvals, and training building blocks Shipped Jul 2026

    Project creation, approval queues, guide review, and training-oriented admin surfaces are already present as building blocks.

    Use it: create projects in Studio today, and use the existing admin review surfaces for approval and training workflows.

  • Done
    AI CAD prompting Shipped Jul 15, 2026

    Natural-language geometry generation and modification via GPT-5.5 Pro, STEP/GLB outputs, and stronger prompt guidance.

    Use it: open Studio, write size + units + intent in the AI prompt, choose a mode, then Generate.

  • Done
    Geometric references Shipped Jul 15, 2026

    Pick corners, faces, edges, lasso regions, and Line paths; reference them in prompts with @corner-1, @face-1, or @path-1 chips.

    Use it: choose Face, Edge, Corner, Lasso, or Line, click geometry, then write an edit around the inserted chip.

  • Done
    Project references in prompts Shipped Jul 15, 2026

    Shift-select files or pick model items, then drag them into AI prompts as context for more accurate generations.

    Use it: select project files in the explorer, drag them into the prompt, and describe how the model should use them.

  • Done
    Electronics and component workflow Shipped Jul 15, 2026

    Component profiles, drag-to-prompt, drag-to-wiring, driver-aware motor validation, generated code, and actuator simulation.

    Use it: switch to Wiring, drag a CAD component into the wiring prompt or board, then generate and validate the circuit.

  • Done
    Reference markup Shipped Jul 15, 2026

    Open PDFs/images, draw callouts, add notes, and send marked-up references into the AI prompt.

    Use it: upload an image/PDF, mark it up with Pen and notes, then click Send to AI.

  • Done
    Canvas sketch mode Shipped Jul 15, 2026

    Sketch concepts in the Canvas design tab and attach them to the AI prompt as visual intent.

    Use it: switch to Canvas, sketch the layout, then attach the sketch before generating CAD.

  • Done
    Shared folders and collaboration Shipped Jul 15, 2026

    Private folder sharing, live workspace context, share links, remix/import flows, and management notifications.

    Use it: right-click a folder or share a model link, then choose who can access or remix it.

  • Done
    Render Agent help and tips Shipped Jul 15, 2026

    Movable Render Agent panel, Getting Started questions, auto-send tip prompts, GIF replies, and clearer rich-message formatting.

    Use it: click Agent or “Ask about this tip” to get contextual workflow help.

  • Done
    Agent Store public documentation Shipped Jul 15, 2026

    Approved submitted agents now appear in searchable public documentation by most recent listing and category.

    Use it: open Docs → Agent Store docs to search public agents, then view or install them in the store.

  • Done
    Getting Started and first-run onboarding Shipped Jul 15, 2026

    GitBook-style Getting Started navigation, Tips & Tricks tab, branded link previews, first-visit welcome popup, and Show Me walkthroughs.

    Use it: open Getting Started, choose a section, then click Show me or Ask Render Agent.

  • Done
    Import, export, and cloud CAD Shipped Jul 15, 2026

    STL, OBJ, GLB/GLTF, PLY, OFF, STEP-sidecar workflows, Fusion/Onshape library panels, and share preview exports.

    Use it: upload CAD, connect Fusion/Onshape, or open a share link and import/remix into a project.

  • Done
    Workspace quality of life Shipped Jul 15, 2026

    Stop generation, project prompt drafts, color/transparent tools, context-menu hide/show, feedback requests, and expanded AI cost analytics.

    Use it: open Studio controls, account preferences, or management inbox depending on the workflow.

Near-term roadmap

  • In progress
    Viewport language: VR first

    WebXR already supports both AR and VR sessions. The next step is making the buyer-facing product language feel consistently VR-forward instead of split between AR and VR labels.

  • Planned
    Click on PC, enter Workshop

    Workshop becomes a clearer spatial destination from desktop entry points instead of remaining an implied extension of Studio and XR.

  • Planned
    No-headset desktop Workshop

    Desktop users enter a 3D printer or workshop scene with walk, mouse look, and spatial move/place flows instead of staying limited to orbit-style navigation.

  • In progress
    Editor tab for shop placement and live voice prompts

    Placement tools, cursor-follow previews, and live voice prompting come together in a clearer editor workflow for spatial scene-building.

  • Planned
    God Mode for agents and tasks

    A room-scale operating view for agents, their current jobs, and the approvals or follow-ups that need a human decision next.

  • In progress
    Project tabs for create, train, and approve

    Project creation, training workflows, and click-to-approve actions move closer to the main Studio experience instead of living in separate surfaces.

  • In progress
    Manage Render Agents, Queue, and Debug in Studio Lab

    Queue visibility, agent operations, and debugging tools converge into one cleaner operating surface for advanced teams.

  • Planned
    Human-gated teleop controls

    Teleop grows around Y-tap engage/pause, hold-Y disarm, robotics-menu priority while teleop is active, and clear session-state cues so a green state obviously means a real live session.

Future of VR and robots

  • Planned
    Personal VR Workshop and shared Workshop scenes

    Workshop becomes a default entry environment for solo build sessions, public demos, and shared team review spaces.

  • Planned
    Human-gated teleop training school

    A supervised training model for robotics workflows, centered on human approval and safety, not on claiming that AI runs physical robot arms live by default.

  • Planned
    Cloud compute seats and optional host marketplace

    Teams gain heavier build, training, and simulation capacity without assuming every workflow runs on one local machine.

  • Planned
    Agent identity bridge, team chat, success loops, and receipts

    People, agents, approvals, outcomes, and visible success loops become easier to follow through one clearer shared operating loop on the Render site.

  • Planned
    Sandbox IDE tabs streaming into Workshop

    Viewers, charts, cameras, and operator tools appear as first-class Workshop surfaces instead of separate flat utilities.

  • Planned
    Stronger agent orchestration for build and train pipelines

    Agents prepare work, pause for approvals, and continue through clearer human gates across build, training, and review flows.
