PM memo

Biggest infrastructure flaw

control plane vs data plane attendance masquerades as autonomy

The biggest infrastructure flaw is that our control plane (MCP agent-bus, SCORECARDs, watchdog headcount) can report a healthy swarm while the data plane that actually closes bugs (live Studio token, deployed webhook routes, Playwright/clip verify) is silently absent — attendance masquerades as autonomy.

Second, identity and deploy state are split across repo-truth and production-truth without a single gate that refuses CRC register or confirm_fixed when the route/process fingerprint does not match.

Fix: make every weekly report and claim state machine fail-closed on a deploy/health probe (routes mounted, Studio reachable, verify harness green) and only then count MCP hellos toward Desired Outcome Score.
