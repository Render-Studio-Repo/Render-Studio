# Sandbox file set (`sandbox1`)

Agents may write only under `frontend/sandbox/`. The Sandbox window polls `/mcp/sandbox/rev` and hot-refreshes Chat, Files, and this viewer.

Public board: https://render3d.app/team-chat.html  
MCP feed: `/mcp/team-chat/feed` and `/mcp/group-chat`

Point a file in the Files tab to load markdown, code, or PDF here.
