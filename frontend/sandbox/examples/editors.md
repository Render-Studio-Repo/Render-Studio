|---|---|---|

| Whiteboard | NE | Smart whiteboard |
| Canvas | NE | 2D draw |
| Photo | NE | Load + annotate + set reference for Astra |
| Imagine / image | NE | 2D preview |
| Video / clip | NE | 2D video, clipperf1. Product Video Editor stays in Studio. |
| Audio | NE | 2D `<audio>` |
| Texture | NE | 2D swatch |
| Wiring | NE catalog | 2D SVG |
| Parts / BOM | NE catalog | 2D list |
| McMaster | NE catalog | mcmtab1-style search iframe |
| DXF | NE | 2D stub (no extra WebGL) |
| PDF | NE | Pitch (`mktpitch1`) + Slideshow (`mktpres1`) + Voice bench (`rnddemo1`, keep both). Point left/right to step. |
| Tasks | SW | Per-agent lists. Sam assigns. Ledger announces done into live stats. |
| Notes / MD | NE | pitch outline + RnD benchmarks |
| Spreadsheet / CSV | NE | table text |
| Team chat | debugger-sized band | MCP feed |
| Pad | SW | collab pad |
| Debugger VR | SE | Enter with bots · live controls · generate analysis · route to Repair |
| Projects | SE (first) | Browse Studio projects · duplicate into sandbox · bots keep `live/code-updates-link.md` |
| File IDE | SE | generate/save loops under `frontend/sandbox/` |
