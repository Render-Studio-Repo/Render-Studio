# DiMOS install pointer

Upstream lives at [github.com/dimensionalOS/dimos](https://github.com/dimensionalOS/dimos).

Clone into the ignored checkout path (repo-relative):

```bash
bash integrations/install.sh dimos
# → integrations/dimos/
export DIMOS_HOME="$PWD/integrations/dimos"
```

See [`integrations/README.md`](./README.md) for the full catalog.
