# SQ-08 — Standardized connector / robot kit export

**Status:** `side_quest`  
**Why this matters later:** Connectors are **standardized and out of the design loop** (locked decision). Design never generates them.

### Fantasy
After a building exists as centerline walls + openings, an export pass stamps **standard** snap connectors / printable kit parts onto the model (or generates a kit BOM). One connector system to rule them all — not per-wall AI invention.

### Why not now
Would add noise to design steps and fight the domino UI. Draw-walls + `building.json` first; then a single export pipeline.
