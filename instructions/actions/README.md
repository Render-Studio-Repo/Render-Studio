(for example: pre-push checks, PR hygiene, verification recipes).

Keep server publishing / branding / profile-import docs under
`instructions/server/` instead.

| Doc | When to read |
| --- | --- |
| [PUBLISH-SERVER-UPDATES.md](./PUBLISH-SERVER-UPDATES.md) | Before posting product updates from the update log |
| [PUSH-AND-PR.md](./PUSH-AND-PR.md) | Before pushing branches or opening PRs |
