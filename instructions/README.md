# Agent instructions index

1. Always start at [`../AGENTS.md`](../AGENTS.md) and [`../ai-context/START-HERE.md`](../ai-context/START-HERE.md).
2. Then open the folder that matches the job:
   - [`server/`](./server/) — server settings, update publishing, branding/profile import
   - [`actions/`](./actions/) — non-server action playbooks (push/PR/verify helpers)

When an instruction says “read X before doing Y”, that file belongs in one of
these folders so agents can discover it consistently.
